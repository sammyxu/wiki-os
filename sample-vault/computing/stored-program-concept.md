# Stored-Program Concept

The stored-program concept is the idea that a computer's instructions can be held in the same memory as its data, so programs can be loaded, edited, and even manipulated by other programs. It is the architectural foundation of virtually every computer built since the late 1940s.

The idea was set out in the 1945 "First Draft of a Report on the EDVAC," circulated under the name of [[people/john-von-neumann|John von Neumann]] and drawing on work by the [[computing/eniac|ENIAC]] engineers J. Presper Eckert and John Mauchly. It had a theoretical ancestor in [[people/alan-turing|Alan Turing]]'s 1936 universal [[computing/turing-machine|Turing machine]], which showed that a single machine could run any program supplied to it as data. On 21 June 1948 the Manchester Baby became the first machine to execute a program from electronic memory, followed by Cambridge's EDSAC in 1949.

## Why It Mattered

- Reprogramming became a matter of loading new instructions, not rewiring plugboards for days as on ENIAC.
- Programs could treat other programs as data, enabling assemblers, compilers, and operating systems.
- The resulting "von Neumann architecture" remains the template traced throughout the [[computing/history-of-computing|history of computing]].
