# Unix

Unix is an operating system begun in 1969 at Bell Labs by Ken Thompson and Dennis Ritchie. Its design philosophy — small programs that do one thing well, composed through pipes and plain text — shaped how software has been built ever since.

Thompson wrote the first version on a spare PDP-7 after Bell Labs withdrew from the ambitious Multics project. In 1973 the system was rewritten in Ritchie's new C language, making Unix portable across hardware — a radical idea when operating systems were written in assembly for one machine. Because AT&T was barred from selling software, Unix was licensed cheaply to universities with source code included. At Berkeley, the BSD variant added TCP/IP networking, making Unix the workhorse of the [[computing/arpanet|ARPANET]] and later the servers of the [[computing/world-wide-web|World Wide Web]].

## A Living Legacy

The tradition of shared, studied source code fed directly into the [[computing/open-source-movement|open source movement]]: Linux, a Unix-like kernel released by Linus Torvalds in 1991, now runs most servers and Android devices, while macOS descends from BSD. Few systems have threaded through the [[computing/history-of-computing|history of computing]] so persistently.
