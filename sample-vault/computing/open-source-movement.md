# Open Source Movement

The open source movement holds that software source code should be free to read, modify, and share, turning programming into a global collaborative enterprise. Its rise is a defining thread in the recent [[computing/history-of-computing|history of computing]].

Richard Stallman launched the GNU Project in 1983 to rebuild a free [[computing/unix|Unix]]-like system, founding the Free Software Foundation in 1985 and drafting the GPL, a license that requires derived works to stay free. Linus Torvalds released the Linux kernel in 1991, and its bazaar-style development, analyzed in Eric Raymond's 1997 essay "The Cathedral and the Bazaar", proved that distributed volunteers could build industrial-strength software. The term "open source" was adopted in 1998, when the Open Source Initiative was founded to promote the model to business.

## Why it won

Open code compounds: every contributor benefits from every other, a dynamic closely related to [[systems/network-effects|network effects]]. Today Linux runs most servers and every Android [[computing/personal-computer|personal computer]]'s smartphone cousin, while debates about software freedom continue within the [[philosophy/ethics-of-technology|ethics of technology]].
