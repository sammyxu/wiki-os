# World Wide Web

The World Wide Web is the system of linked documents and resources that made the internet usable by everyone, built on three simple inventions: URLs, HTTP, and HTML. It stands among the most consequential developments in the [[computing/history-of-computing|history of computing]].

[[people/tim-berners-lee|Tim Berners-Lee]] proposed the Web in March 1989 while working at CERN, aiming to help physicists share documents across incompatible systems. He wrote the first browser and server in 1990, and the first website went live in 1991 on the internet infrastructure descended from [[computing/arpanet|ARPANET]]. The core idea, that any document can link directly to any other, came from decades of [[computing/hypertext|hypertext]] research. CERN's 1993 decision to release the technology royalty-free, together with the Mosaic browser that same year, triggered explosive growth driven by powerful [[systems/network-effects|network effects]].

## The three building blocks

- URL: a universal address for any resource on the network
- HTTP: a simple protocol for requesting and delivering documents
- HTML: a markup language for structuring pages and embedding links
